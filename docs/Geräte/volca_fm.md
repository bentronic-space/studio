# Korg Volca FM

**ID:** `volca_fm`
**Typ:** synthesizer
**Status:** active
**Ort:** studio

## Technische Fähigkeiten

- midi
- midi_din
- fm_synthesis
- sync
- sysex

## Musikalische Fähigkeiten

- synthesizer
- sequencing
- arpeggiator
- sound_design

## Anschlüsse

- **MIDI IN** (`midi_in`) – midi, input
- **Audio OUT** (`audio_out`) – audio, output
- **SYNC IN** (`sync_in`) – sync, input
- **SYNC OUT** (`sync_out`) – sync, output
- **Power** (`power`) – power, input

## Verbindungen

### Ausgänge

Keine aktiven Ausgänge.

### Eingänge

Keine aktiven Eingänge.

## Notizen

- FM synthesizer with 6 operators and 32 algorithms.
- MIDI input supports loading SYX/SYS-EX files created for Yamaha DX7.
- Audio output is a 3.5 mm stereo mini jack.
- Sync input and output use 3.5 mm mono mini jack.
- Two Volca FM units can exchange sound programs and sequence data via sync.
