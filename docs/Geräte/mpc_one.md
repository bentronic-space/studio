# Akai MPC One

**ID:** `mpc_one`  
**Typ:** standalone_sequencer  
**Status:** active  
**Ort:** studio

## Technische Fähigkeiten

- midi
- midi_din
- sequencer
- sampler
- cv_gate
- usb
- sd_storage
- q_link
- touchscreen

## Musikalische Fähigkeiten

- sequencing
- sampling
- beatmaking
- live_performance

## Anschlüsse

- **MIDI IN** (`midi_in`) – midi, input
- **MIDI OUT** (`midi_out`) – midi, output
- **Audio IN L** (`audio_in_l`) – audio, input
- **Audio IN R** (`audio_in_r`) – audio, input
- **Audio OUT L** (`audio_out_l`) – audio, output
- **Audio OUT R** (`audio_out_r`) – audio, output
- **Headphones** (`headphones_out`) – audio, output
- **CV/Gate 1** (`cv_gate_1`) – cv_gate, output
- **CV/Gate 2** (`cv_gate_2`) – cv_gate, output
- **CV/Gate 3** (`cv_gate_3`) – cv_gate, output
- **CV/Gate 4** (`cv_gate_4`) – cv_gate, output
- **USB Host** (`usb_a`) – usb, bidirectional
- **USB Device** (`usb_b`) – usb, bidirectional
- **SD Card** (`sd_card`) – storage, bidirectional
- **Power** (`power`) – power, input
